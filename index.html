Experimente agora

A caixa abaixo é um terminal simulado: uma máquina fictícia chamada notebook, com a usuária ana, rodando o Bash. Ela funciona dentro desta página e nada do que você digitar mexe no seu computador. Clique na janela escura, digite echo Olá e aperte Enter.

Missão: digite echo Olá e aperte Enter. O echo ("eco") repete na tela o que você escreveu depois dele. Depois, se quiser, experimente echo Olá, $USER e ls.

O que aconteceu: você escreveu um comando (echo) seguido de um argumento (Olá). O Bash leu a linha, achou o comando e o executou. O echo devolveu o texto na tela e um novo prompt apareceu, esperando o próximo comando. É isso que o Bash faz o dia inteiro: ler, entender e executar o que você pede.

$ echo Olá
Olá                                « a resposta do comando
$ echo Olá, $USER
Olá, ana                           « o Bash trocou $USER pelo nome da usuária

O que é este guia

O Bash é o programa que entende os comandos que você digita no terminal. Ele está em quase todo Linux, no macOS, no Windows (pelo WSL e pelo Git Bash) e até no Android (pelo Termux). Quem sabe Bash consegue:

  • usar o terminal sem medo: navegar, procurar, copiar e organizar arquivos;
  • juntar comandos pequenos para resolver problemas grandes (|, >, &&);
  • escrever scripts: arquivos com comandos que fazem tarefas repetitivas sozinhos, como backups e relatórios;
  • entender scripts dos outros: instaladores, arquivos de configuração, automações de servidor.

O guia começa do zero absoluto (o que é um terminal?) e vai até scripts robustos, com tratamento de erros, opções de linha de comando e processos em paralelo. A aula O que é o Bash conta a história e mostra o que acontece entre você e o sistema.

Como as aulas funcionam

Nenhum comando aparece "seco". Toda aula segue o mesmo caminho:

  1. A ideia primeiro. Antes do comando, você entende o problema que ele resolve, com um exemplo do dia a dia.
  2. Anatomia do comando. Cada pedaço é numerado e explicado: o comando, as opções e os argumentos. Nos scripts, cada linha.
  3. Terminal com a resposta. Você vê exatamente o que aparece na tela, com etiquetas laranja apontando o que importa. Toda saída foi conferida no GNU Bash 5.3 de verdade.
  4. O que ele devolve. Além do texto na tela, todo comando devolve um código de saída (0 = deu certo). As aulas mostram esse código, principalmente quando "não aparece nada".
  5. Várias formas de fazer. Quase sempre há mais de um caminho, e uma tabela "Qual usar?" mostra quando escolher cada um.
  6. Quando não funciona. As mensagens de erro reais, por que acontecem e como resolver.
  7. Experimente e exercícios. Missões no terminal simulado e no editor de script, e exercícios com correção na hora.

Exemplo: a anatomia de um comando

Quantas linhas tem o arquivo frutas.txt da Ana? O comando wc (de word count, "contagem de palavras") conta linhas, palavras e letras. Veja como as aulas desmontam um comando:

wc
O comando: o programa que vai trabalhar. Ele conta coisas num texto.
-l
Uma opção: muda o comportamento. -l (de lines, "linhas") pede só o número de linhas.
frutas.txt
O argumento: em que o comando vai trabalhar, aqui o nome do arquivo.
$ wc -l frutas.txt
7 frutas.txt                       « 7 linhas, seguidas do nome do arquivo contado
$ echo $?
0                                  « código de saída 0: deu certo

A primeira resposta diz que o arquivo tem 7 linhas (uma fruta por linha). O echo $? mostra o código de saída do último comando: 0 quer dizer "sem erro". A aula Anatomia de um Comando explica opções e argumentos a fundo.

Exemplo: o editor de script

Além do terminal, o guia tem um editor de script, o "Try it Yourself" daqui. Você muda o código, clica em Rodar e vê a saída e o código de saída. O script abaixo recebe um nome como argumento (o campo de argumentos já vem com Ana) e cumprimenta essa pessoa. Antes de mexer, leia o que cada linha faz:

LinhaO que faz
#!/usr/bin/env bashA "linha shebang": diz que o arquivo deve ser rodado pelo Bash.
nome=$1Guarda o primeiro argumento ($1) numa variável chamada nome.
echo "Olá, $nome!"Mostra o texto, trocando $nome pelo valor guardado.
echo "Sua lista tem $(wc -l < frutas.txt) frutas."Roda o wc e cola o resultado dele no meio do texto.

Missão: clique em Rodar para ver o resultado. Depois mude o script para dizer Bom dia em vez de Olá e rode de novo. Se quiser, troque o argumento Ana pelo seu nome.

#!/usr/bin/env bash
nome=$1
echo "Olá, $nome!"
echo "Sua lista tem $(wc -l < frutas.txt) frutas."

#!/usr/bin/env bash
nome=$1
echo "Bom dia, $nome!"
echo "Sua lista tem $(wc -l < frutas.txt) frutas."

Rodando sem mudar nada, a saída é esta. Cada linha da saída veio de um echo do script:

$ bash saudacao.sh Ana
Olá, Ana!
Sua lista tem 7 frutas.

Não se preocupe se $1 e $( ) ainda parecem mágica: cada um tem a sua aula (Argumentos e Substituição de Comando). A aula Terminal Simulado ensina a usar o terminal e o editor, e mostra o que eles sabem e não sabem fazer.

Como ler este guia

ElementoO que significa

> no começo da linhaContinuação: o comando anterior ainda não terminou e o Bash espera o resto (o prompt secundário).
root@notebook:~#Comando rodado como administrador (root). O # no fim avisa que você pode mexer em tudo.
Linhas sem promptA resposta do computador.
← etiquetaUma explicação do guia sobre aquela linha. Não aparece no terminal real.
<texto>Troque pelo seu valor. Ex.: cd <pasta> vira cd Documentos.
[opcional]Parte que pode ser omitida.
bash 5.3+O recurso só existe a partir dessa versão do Bash. A aula diz a alternativa para versões mais antigas.
Versão de referência: GNU Bash 5.3

Todas as saídas foram conferidas no GNU Bash 5.3, em português do Brasil, com as ferramentas GNU (as do Linux). O Bash 5.3 vem no Ubuntu 26.04, no Fedora e no Arch. O Debian 13 e o Ubuntu 24.04 têm o 5.2, que é quase igual. O macOS vem com o antigo 3.2: a aula Bash em Cada Sistema mostra como instalar um mais novo.
