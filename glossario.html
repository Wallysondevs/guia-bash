Bash Glossário

Os termos que aparecem no guia, em ordem alfabética, explicados em uma ou duas frases e com o link para a aula onde o assunto é ensinado. Quando o termo em inglês é muito usado, ele aparece entre parênteses, para você reconhecê-lo em documentações e fóruns.

A · B · C · D · E · F · G · H · I · J · L · M · N · O · P · R · S · T · V · X

A

Alias (apelido)
Um nome curto que o Bash troca por um texto maior antes de executar: alias ll='ls -alF'. Só vale no terminal interativo (em scripts vem desligado). Para algo com argumentos, use uma função. Veja: alias.
Argumento
Cada palavra que vem depois do nome do comando: em cp -r fotos backup, -r, fotos e backup são argumentos (o primeiro é uma opção). Num script, chegam em $1, $2… Veja: Anatomia de um Comando e Argumentos.
Aritmética (expansão aritmética)
Contas com números inteiros dentro de $(( )) ou (( )): echo $((2 + 3)). Sem casas decimais; para isso, bc ou awk. Veja: Contas.
Array (vetor, lista)
Uma variável que guarda vários valores, numerados a partir de 0: frutas=(banana uva), ${frutas[1]}. Veja: Arrays.
Array associativo (dicionário)
Um array cujos índices são textos: declare -A capital=([SP]="São Paulo"). Ótimo para contar "por nome". bash 4.0+ Veja: Arrays Associativos.
Arquivo oculto
Arquivo cujo nome começa com ponto (.bashrc). Não aparece no ls nem no curinga *; aparece com ls -a. Veja: ls.
Aspas
Dizem ao Bash o que não mexer: entre aspas simples, nada é expandido; entre aspas duplas, só $, ` e \. Proteger variáveis com aspas duplas evita a maioria dos erros com espaços. Veja: Aspas e Escapes.
awk
Uma pequena linguagem para processar texto por colunas (campos): awk '{print $1}' mostra a primeira coluna. Muito mais rápido que um laço do Bash em arquivos grandes. Veja: grep, sed, awk e cia.

B

Bash
Bourne-Again SHell, "o shell Bourne de novo" (um trocadilho com born again, "renascido"): o shell do projeto GNU, de 1989, sucessor do Bourne shell (sh). É o shell padrão da maioria das distribuições Linux. Veja: O que é o Bash.
Bashismo
Recurso que existe no Bash mas não no sh do POSIX (como [[ ]], arrays, ${x,,}). Um script com bashismos deve começar com #!/usr/bin/env bash, não #!/bin/sh. Veja: POSIX sh e Bashismos.
Builtin
Veja Comando interno.

C

Caminho absoluto / relativo
Absoluto começa na raiz / (/home/ana/Documentos) e funciona de qualquer lugar; relativo parte da pasta atual (Documentos/notas.txt, ../fotos). Veja: Navegar.
Código de saída (exit status)
O número que todo comando devolve ao terminar: 0 = deu certo; qualquer outro (1 a 255) = algum problema. Fica em $? e é o que o if, o && e o || olham. 126 = sem permissão, 127 = comando não encontrado, 130 = interrompido com Ctrl+C. Veja: Código de Saída.
Comando externo
Um programa que é um arquivo em alguma pasta do PATH (/usr/bin/ls). Para rodá-lo, o Bash cria um processo novo. Veja: PATH.
Comando interno (builtin)
Um comando que faz parte do próprio Bash (cd, echo, read, export): roda sem criar processo e pode mudar o shell. type cd responde "cd é um comando interno do shell". Veja: Comandos Internos e Obtendo Ajuda.
Completar (completion)
O Tab terminando nomes de comandos, arquivos e variáveis por você. Com complete, cada comando pode ter sugestões próprias. Veja: Completar com Tab e Completar Programável.
Console
Originalmente, o terminal físico ligado direto à máquina; hoje, também o terminal em modo texto do sistema (Ctrl+Alt+F3). Veja: Terminal, Shell e Console.
Crases
A forma antiga da substituição de comando: `date`. Prefira $(date), que pode ser aninhada e é mais legível. Veja: Substituição de Comando.
CRLF
A quebra de linha do Windows (\r\n). Um script salvo assim falha no Linux com mensagens que mencionam $'\r' ou ^M. Conserte com sed -i 's/\r$//' script.sh. Veja: Erros Comuns.
cron
O serviço que roda comandos em horários marcados, configurado com crontab -e. Veja: Agendar Scripts.
Curinga (glob, wildcard)
Os caracteres *, ? e [ ], que o Bash troca pelos nomes de arquivos que casam: *.txt. Com extglob há formas extras como !(*.txt). Veja: Curingas.

D

dash
Um shell pequeno e rápido, compatível com o POSIX, que é o /bin/sh do Debian e do Ubuntu. Não entende bashismos. Veja: POSIX sh e Bashismos.
Descritor de arquivo (file descriptor)
O número que um processo usa para falar com um arquivo aberto: 0 = entrada padrão, 1 = saída padrão, 2 = saída de erro. Em 2>erros.txt, o 2 é o descritor. Com exec 3>arq você abre outros. Veja: Redirecionamento e Descritores.
Dotfiles
Os arquivos de configuração com nome começado por ponto na pasta pessoal (.bashrc, .inputrc), e, por extensão, o costume de guardá-los num repositório. Veja: Seus Dotfiles.

E

Entrada padrão (stdin)
De onde um programa lê: por padrão, o teclado; com < arquivo ou um pipe, outro lugar. É o descritor 0. Veja: Redirecionamento.
Escape
A barra invertida \ que tira o significado especial do próximo caractere (\$, \ ). Também as sequências como \n e \t do printf e do $'…'. Veja: Aspas e Escapes.
eval
Comando que monta um texto e o executa como código. Poderoso e perigoso com dados vindos de fora; quase sempre há alternativa melhor. Veja: eval e indireção.
Expansão
Cada transformação que o Bash faz na linha antes de executar: chaves, til, variáveis, aritmética, substituição de comando, separação de palavras, curingas e remoção de aspas, nessa ordem. Veja: A Ordem das Expansões e Cola de Expansões.
Expansão de chaves (brace expansion)
{a,b} e {1..10} gerando listas de palavras, sem olhar se os arquivos existem. Veja: Chaves.
Expansão de parâmetros
As formas ${…} de usar uma variável: valor padrão (${x:-p}), tamanho (${#x}), cortes (${x%.txt}), trocas (${x//a/b}). Veja: Expansão de Parâmetros.
export
Marca uma variável para ser copiada para os programas que o shell iniciar, tornando-a uma variável de ambiente. Veja: Variáveis, Escopo e export.

F

Função
Um bloco de comandos com nome, chamado como se fosse um comando: saudar() { echo "Olá, $1"; }. Roda no próprio shell, por isso pode mudar a pasta e as variáveis. Veja: Funções e local, return e Saída.

G

getopts
Comando interno que lê opções de uma letra (-v, -o arquivo) num laço. Veja: Opções com getopts.
Glob, globbing
Veja Curinga.
GNU
O projeto de software livre que criou o Bash e as ferramentas básicas do Linux (ls, cp, grep, sed…, os "coreutils"). No macOS, essas ferramentas são as do BSD, com opções um pouco diferentes. Veja: Bash em Cada Sistema.

H

Here-doc (documento aqui)
Um bloco de texto de várias linhas que vira a entrada de um comando, terminando numa palavra marcadora: cat <<FIM … FIM. Veja: Here-docs e Here-strings.
Here-string
Uma linha de texto como entrada de um comando: read a b <<< "x y". Veja: Here-docs e Here-strings.
Histórico
A lista dos comandos que você digitou, guardada em ~/.bash_history; navegue com ↑ e busque com Ctrl+R. Veja: Histórico.
HOME
A sua pasta pessoal (/home/ana), guardada na variável $HOME e abreviada como ~. Veja: Navegar.

I

Idempotente
Diz-se de um script que pode rodar várias vezes seguidas sem estragar nada: a segunda execução não muda o que a primeira já fez. Veja: Organizar Downloads e Boas Práticas.
IFS
Internal Field Separator, "separador interno de campos": os caracteres onde o Bash corta o resultado de uma expansão sem aspas e onde o read divide a linha. Padrão: espaço, TAB e quebra de linha. Veja: Ler Arquivos Linha a Linha e Aspas.
Indireção
Usar o valor de uma variável como nome de outra: ${!nome}, ou um nameref com declare -n. Veja: eval, Indireção e nameref.
Interativo (shell interativo)
O shell em que você digita, com prompt; lê o ~/.bashrc. Um script roda num shell não interativo. $- contém i no interativo. Veja: Arquivos de Inicialização.

J

Job (trabalho)
Um comando (ou pipeline) iniciado pelo shell, que pode estar em primeiro plano, em segundo plano (&) ou parado (Ctrl+Z). Listados com jobs, referidos como %1, %2. Veja: Jobs.

L

Laço (loop)
Um bloco que se repete: for (para cada item), while (enquanto), until (até que). Veja: for e while e until.
Link simbólico (symlink, atalho)
Um arquivo que aponta para outro caminho, criado com ln -s destino nome. No ls -l, aparece com l e uma seta. Veja: Criar, Copiar e Mover.
local
Declara uma variável que só existe dentro da função. Veja: local, return e Saída.
Login (shell de login)
O primeiro shell de uma sessão (ao entrar por SSH ou no console), que lê o ~/.profile ou o ~/.bash_profile. Veja: Arquivos de Inicialização.

M

mapfile / readarray
Comando interno que lê um arquivo (ou a saída de um comando) para um array, uma linha por item. Veja: mapfile e readarray.
Modo estrito
O apelido de set -euo pipefail no começo de um script: para no primeiro erro, trata variável inexistente como erro e não esconde falhas dentro de pipes. Veja: set -euo pipefail.

N

Nameref
Uma variável que é um apelido de outra: declare -n ref=contador; mexer em ref mexe em contador. Útil para passar arrays para funções. bash 4.3+ Veja: eval, Indireção e nameref.

O

Opção (flag)
Um argumento que muda o comportamento do comando, normalmente começando com - (-l) ou -- (--all). Veja: Anatomia de um Comando.
Opções do shell
Interruptores que mudam o comportamento do próprio Bash: os do set (-e, -x, -o noclobber) e os do shopt (nullglob, globstar). Veja: Opções do Shell.
Operador de controle
Os símbolos que separam e encadeiam comandos: ; (um depois do outro), && (só se o anterior deu certo), || (só se falhou), | (pipe), & (em segundo plano). Veja: ; && ||.

P

Palavra reservada (keyword)
Palavra com significado na gramática do Bash, como if, then, for, do, done, case, [[. Não é um comando: type if responde "if é uma palavra-chave do shell". Veja: Comandos Internos.
Parâmetro posicional
Os argumentos de um script ou função: $1, $2…, contados em $# e todos juntos em "$@". Veja: Argumentos.
PATH
A variável com a lista de pastas, separadas por :, onde o Bash procura os comandos que você digita. Se um programa não está numa delas, aparece "comando não encontrado". Veja: PATH.
PID
Process ID: o número que identifica um processo. O do shell está em $$; o do último comando em segundo plano, em $!. Veja: Jobs.
Pipe e pipeline
O | liga a saída de um comando à entrada do próximo: sort nomes.txt | uniq. A sequência inteira é um pipeline. Veja: Pipes.
POSIX
A norma que define o que um shell sh e as ferramentas básicas de um sistema tipo Unix devem fazer. Um script só com recursos POSIX roda no dash, no bash, no zsh… Veja: POSIX sh e Bashismos.
Primeiro plano / segundo plano (foreground / background)
Em primeiro plano, o comando ocupa o terminal até terminar; em segundo plano (com & no fim), ele roda enquanto você continua usando o prompt. Veja: Jobs.
Processo
Um programa em execução, com memória e PID próprios. Cada comando externo roda num processo novo, filho do shell. Veja: Subshells e Grupos.
Prompt
O texto que o shell mostra quando espera um comando (ana@notebook:~$), definido pela variável PS1. Veja: Lendo o Prompt e Personalizar o Prompt.

R

readline
A biblioteca que cuida da edição da linha no Bash: setas, Ctrl+A, Ctrl+R, Tab. Configurada no ~/.inputrc. Veja: Editar a Linha e Atalhos do Teclado.
Redirecionamento
Mudar de onde um comando lê ou para onde escreve: > (grava), >> (acrescenta), < (lê de arquivo), 2> (erros), 2>&1 (erros junto com a saída). Veja: Redirecionamento.
Regex (expressão regular)
Uma linguagem de padrões de texto (^[0-9]+$ = "só dígitos"), usada no [[ =~ ]], no grep, no sed. Diferente dos curingas. Veja: Regex com [[ =~ ]].
root
O administrador do sistema (usuário número 0), que pode tudo. Comandos de administração são rodados como root com sudo; o prompt dele termina em #. Veja: Lendo o Prompt.

S

Saída de erro (stderr)
O canal separado (descritor 2) onde os programas escrevem as mensagens de erro, para elas não se misturarem com o resultado. Num script: echo "erro" >&2. Veja: Redirecionamento e Tratar Erros.
Saída padrão (stdout)
Para onde um programa escreve o resultado: por padrão, a tela. É o descritor 1, o que vai para um > arquivo ou um pipe. Veja: Redirecionamento.
Script
Um arquivo de texto com comandos que o shell executa em sequência. Veja: Seu Primeiro Script.
sed
O "editor de fluxo": transforma texto linha a linha, sem abrir editor (sed 's/velho/novo/g'). Veja: grep, sed, awk e cia.
Separação de palavras (word splitting)
A etapa em que o Bash corta o resultado de uma expansão sem aspas nos caracteres do IFS. É por isso que $arquivo com espaço no nome vira dois argumentos, e "$arquivo" não. Veja: Aspas e A Ordem das Expansões.
Shebang
A primeira linha de um script, começando com #! (hash-bang), que diz qual programa deve executá-lo: #!/usr/bin/env bash. Veja: Seu Primeiro Script.
Shell
O programa que lê os comandos que você digita (ou de um script) e os executa: a "casca" em volta do sistema. Bash, zsh, dash e fish são shells. Veja: Terminal, Shell e Console.
ShellCheck
Um programa que lê scripts e aponta erros e más práticas, cada um com um código (SC2086) e uma explicação. Veja: ShellCheck.
Sinal (signal)
Um aviso que o sistema manda a um processo: SIGINT (Ctrl+C), SIGTERM (o kill padrão), SIGKILL (kill -9, não pode ser ignorado), SIGHUP (terminal fechado). Um script reage a eles com trap. Veja: trap e Sinais.
source (ou .)
Executa um arquivo dentro do shell atual, em vez de num processo novo: as variáveis e funções dele ficam valendo. É assim que o .bashrc é lido. Veja: Formas de Executar.
Subshell
Uma cópia do shell, criada por ( … ), $( … ), pipes e &. O que muda lá dentro (variáveis, cd) não volta para o shell original. Veja: Subshells e Grupos.
Substituição de comando
$(comando): roda o comando e põe a saída dele no lugar. hoje=$(date +%F). Veja: Substituição de Comando.
Substituição de processo
<(comando): põe no lugar um nome de arquivo de onde se lê a saída do comando, para programas que só aceitam arquivos: diff <(ls a) <(ls b). Veja: Substituição de Processo.

T

Terminal (emulador de terminal)
A janela onde você digita (GNOME Terminal, Konsole, Windows Terminal). Ele só mostra texto e repassa o teclado; quem interpreta os comandos é o shell. Veja: Terminal, Shell e Console.
Teste
Um comando que só responde "verdade" (código 0) ou "falso": [ -f arq ], [[ $x == a* ]], test 5 -gt 3. Veja: Testes.
Til (~)
Abreviação da sua pasta pessoal; ~ana é a da Ana. Só é trocado fora de aspas. Veja: Navegar.
trap
Comando que define o que fazer quando chega um sinal ou o script termina (trap limpar EXIT). Veja: trap e Sinais.

V

Variável
Um nome que guarda um valor (sempre texto, para o Bash): nome=Ana cria (sem espaços em volta do =); $nome usa. Veja: Variáveis: o Básico.
Variável de ambiente
Uma variável exportada, que os programas iniciados pelo shell recebem (HOME, PATH, LANG). env lista todas. Veja: Variáveis, Escopo e export e Variáveis Especiais.
Variável especial
Variável que o Bash preenche sozinho: $?, $#, $$, RANDOM, LINENO… Veja: Variáveis Especiais.

X

xargs
Transforma linhas da entrada em argumentos de um comando: find . -name '*.tmp' -print0 | xargs -0 rm. Com -P, roda vários ao mesmo tempo. Veja: Pipes e Rodar em Paralelo.
