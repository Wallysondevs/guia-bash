Projeto Organizar Downloads

Toda pasta Downloads vira bagunça: fotos, PDFs, músicas e arquivos compactados misturados. Neste projeto você escreve, em seis etapas, um script que separa tudo em subpastas pelo tipo do arquivo. No caminho ele ganha um modo de "só mostrar", aprende a lidar com nomes com espaço, nunca apaga um arquivo por cima de outro, faz um resumo do que fez e guarda um registro (log).

Ao terminar você terá
  • Um script organizar.sh que move cada arquivo de ~/Downloads para Imagens/, Documentos/, Músicas/, Compactados/ ou Outros/.
  • Um modo simulação (-n) que mostra o que seria feito sem mover nada.
  • Proteção contra nomes com espaço e contra sobrescrever arquivos.
  • Um resumo no final ("2 Imagens, 1 Músicas…") feito com um array associativo.
  • Um arquivo ~/organizar.log com tudo o que foi movido.

Antes de programar: o plano

Um script bom começa no papel. A pergunta é: como o computador sabe o tipo de um arquivo? O jeito mais simples é olhar a extensão, o pedaço depois do último ponto (.jpg, .pdf). Não é infalível (nada impede alguém de chamar um PDF de foto.jpg), mas é o que o gerenciador de arquivos faz na maioria das vezes, e é suficiente aqui.

ExtensõesVai para a pasta
.jpg .jpeg .png .gif .webpImagens/
.pdf .odt .docx .txt .csvDocumentos/
.mp3 .ogg .flac .wavMúsicas/
.zip .tar .gz .xz .7zCompactados/
qualquer outra (ou sem extensão)Outros/

As subpastas ficam dentro de ~/Downloads (~/Downloads/Imagens, e não a ~/Imagens da Ana). Assim o script nunca mexe em nada fora da pasta que você mandou organizar. A pasta da Ana começa assim:

$ ls Downloads
foto.jpg          manual.pdf  ubuntu-26.04-desktop-amd64.iso
fotos-viagem.zip  musica.mp3

As etapas

  1. Etapa 1 — Dizer o tipo de cada arquivo (sem mexer em nada)

    O que vamos fazer e por quê: antes de mover qualquer coisa, o script só mostra para onde cada arquivo iria. É a parte mais importante (a classificação) e, como não altera nada, dá para testar à vontade.

    #!/usr/bin/env bash
# organizar.sh — versão 1: só mostra o tipo de cada arquivo
origem=~/Downloads

for arq in "$origem"/*; do
  nome=${arq##*/}
  case ${nome,,} in
    *.jpg|*.jpeg|*.png|*.gif|*.webp) pasta=Imagens ;;
    *.pdf|*.odt|*.docx|*.txt|*.csv)  pasta=Documentos ;;
    *.mp3|*.ogg|*.flac|*.wav)        pasta=Músicas ;;
    *.zip|*.tar|*.gz|*.xz|*.7z)      pasta=Compactados ;;
    *)                               pasta=Outros ;;
  esac
  echo "$nome -> $pasta"
done

  2. Etapa 2 — Mover de verdade, com um modo simulação (-n)

    O que vamos fazer e por quê: agora o script move os arquivos. Mas um script que move coisas precisa de um "ensaio": com -n (de no-act, "não faça", a mesma letra que o make -n e o rsync -n usam) ele só conta o que faria. Aproveitamos para tirar a classificação de dentro do laço e colocá-la numa função.

    #!/usr/bin/env bash
# organizar.sh — versão 2: move de verdade, ou só simula com -n
simular=0
if [[ $1 == -n ]]; then
  simular=1
  shift
fi
origem=${1:-~/Downloads}

tipo_de() {
  case ${1,,} in
    *.jpg|*.jpeg|*.png|*.gif|*.webp) echo Imagens ;;
    *.pdf|*.odt|*.docx|*.txt|*.csv)  echo Documentos ;;
    *.mp3|*.ogg|*.flac|*.wav)        echo Músicas ;;
    *.zip|*.tar|*.gz|*.xz|*.7z)      echo Compactados ;;
    *)                               echo Outros ;;
  esac
}

for arq in "$origem"/*; do
  [[ -f $arq ]] || continue
  nome=${arq##*/}
  pasta=$(tipo_de "$nome")
  if (( simular )); then
    echo "iria mover: $nome -> $pasta/"
  else
    mkdir -p "$origem/$pasta"
    mv -- "$arq" "$origem/$pasta/"
    echo "movido: $nome -> $pasta/"
  fi
done

  5. Etapa 5 — Um resumo no final (array associativo)

    O que vamos fazer e por quê: com 200 arquivos, ninguém lê 200 linhas. Queremos terminar com "2 Imagens, 1 Músicas…". Precisamos de um contador por nome de pasta, e é exatamente isso que um array associativo é: uma tabela em que o índice é um texto. Veja Arrays Associativos.

    declare -A conta                 # no começo do script

    # dentro do laço, no ramo "pulado", antes do continue:
    (( conta[Pulados]++ ))

  # dentro do laço, na última linha (vale para mover e para simular):
  (( conta[$pasta]++ ))

# depois do laço:
echo
echo "Resumo:"
total=0
for p in Imagens Documentos Músicas Compactados Outros Pulados; do
  if [[ -v conta[$p] ]]; then
    printf '%5d  %s\n' "${conta[$p]}" "$p"
    (( total += conta[$p] ))
  fi
done
printf '%5d  %s\n' "$total" "arquivos no total"
    TrechoO que faz
    declare -A contaCria o array associativo. Sem o -A, o Bash trataria conta[Imagens] como índice numérico 0 e somaria tudo no mesmo lugar. bash 4.0+
    (( conta[$pasta]++ ))Soma 1 na posição daquela pasta. Uma posição que não existia vale 0.
    for p in Imagens … PuladosPercorremos as categorias numa ordem fixa. O "${!conta[@]}" também listaria as chaves, mas numa ordem que o Bash escolhe (não alfabética nem de chegada).
    [[ -v conta[$p] ]]"Esta posição existe?" Assim só aparecem as categorias que tiveram arquivos.
    printf '%5d %s\n'Número alinhado à direita em 5 colunas, dois espaços, o nome. Veja printf.

    Por que o número vem antes do nome?

    Para alinhar. O printf do Bash mede a largura de %-12s em bytes, e o "ú" de "Músicas" ocupa 2 bytes em UTF-8. Com o nome na frente, a linha de Músicas sairia um espaço mais curta:

    $ printf "[%-10s]\n" Músicas Imagens
[Músicas  ]
[Imagens   ]

    Com o número primeiro (%5d), só números são alinhados, e eles nunca têm acento.

#!/usr/bin/env bash
# organizar.sh — arruma uma pasta (padrão: ~/Downloads) em subpastas por tipo.
# Uso: organizar.sh [-n] [PASTA]      -n = simulação: só mostra, não move nada

simular=0
if [[ $1 == -n ]]; then
  simular=1
  shift
fi
origem=${1:-~/Downloads}
log=~/organizar.log
declare -A conta

registrar() {
  printf '%s %s\n' "$(date '+%F %T')" "$*" >> "$log"
}

tipo_de() {
  case ${1,,} in
    *.jpg|*.jpeg|*.png|*.gif|*.webp) echo Imagens ;;
    *.pdf|*.odt|*.docx|*.txt|*.csv)  echo Documentos ;;
    *.mp3|*.ogg|*.flac|*.wav)        echo Músicas ;;
    *.zip|*.tar|*.gz|*.xz|*.7z)      echo Compactados ;;
    *)                               echo Outros ;;
  esac
}

if [[ ! -d $origem ]]; then
  echo "organizar: a pasta '$origem' não existe" >&2
  exit 1
fi

for arq in "$origem"/*; do
  [[ -f $arq ]] || continue
  nome=${arq##*/}
  pasta=$(tipo_de "$nome")
  destino=$origem/$pasta
  if [[ -e $destino/$nome ]]; then
    echo "pulado: $nome (já existe em $pasta/)"
    (( simular )) || registrar "PULADO $nome (já existe em $pasta/)"
    (( conta[Pulados]++ ))
    continue
  fi
  if (( simular )); then
    echo "iria mover: $nome -> $pasta/"
  else
    mkdir -p "$destino"
    mv -n -- "$arq" "$destino/"
    echo "movido: $nome -> $pasta/"
    registrar "$nome -> $pasta/"
  fi
  (( conta[$pasta]++ ))
done

echo "Resumo:"
total=0
for p in Imagens Documentos Músicas Compactados Outros Pulados; do
  if [[ -v conta[$p] ]]; then
    printf '%5d  %s\n' "${conta[$p]}" "$p"
    (( total += conta[$p] ))
  fi
done

Usar no seu computador

Salve o script, dê permissão e ensaie primeiro:

$ chmod +x organizar.sh
$ ./organizar.sh -n            « leia a lista com calma
$ ./organizar.sh               « só então de verdade

Se a sua pasta se chama ~/Transferências (comum em sistemas em português de Portugal) ou ~/Download, passe-a como argumento: ./organizar.sh ~/Transferências. Para chamar o script de qualquer pasta, só com o nome, coloque-o em ~/.local/bin (veja PATH e o projeto Uma Ferramenta de Verdade).

Quando não funciona

"Permissão negada" ao rodar ./organizar.sh 
$ ./organizar.sh
bash: ./organizar.sh: Permissão negada

O que aconteceu: o arquivo não tem permissão de execução. Como resolver: chmod +x organizar.sh, ou rode com bash organizar.sh. Veja Formas de Executar.

Tudo vai para Outros

O que aconteceu: provavelmente os padrões do case estão entre aspas ("*.jpg") ou o ${nome,,} virou $nome e os arquivos têm extensão maiúscula. Entre aspas, o * é um asterisco de verdade, não um curinga. Como confirmar: rode com bash -x organizar.sh -n e olhe as linhas + case …. Veja Depurar.

"iria mover: * -> Outros/"

O que aconteceu: a pasta estava vazia e o curinga, sem nada para casar, ficou como o texto *. O [[ -f $arq ]] || continue do script final evita isso (um arquivo chamado * não existe). Outra saída é shopt -s nullglob, que faz o curinga sem resultado sumir. Veja Curingas.

declare: -A: opção inválida

O que aconteceu: você está no macOS, cujo /bin/bash é a versão 3.2, sem arrays associativos (nem ${x,,}). Como confirmar: bash --version. Como resolver: instale um Bash novo (brew install bash) e use #!/usr/bin/env bash, que pega o primeiro bash do PATH. Veja Bash em Cada Sistema.

Não apareceu nada

O que aconteceu: nas versões 2 a 4 (sem resumo), é o esperado quando não há arquivo solto: só há pastas, e todas são puladas. Confira com echo $? (deve ser 0) e ls ~/Downloads.

Desafios extras

  • Renomear em vez de pular: se foto.jpg já existe, mova como foto (1).jpg, foto (2).jpg… Dica: ${nome%.*} é o nome sem extensão e ${nome##*.}, a extensão.
  • Configuração fora do código: leia as regras de um arquivo ~/.config/organizar.conf com linhas jpg=Imagens, usando while IFS== read -r ext pasta (veja Ler Arquivos Linha a Linha).
  • Por idade: com a opção -d 30, mexa só nos arquivos com mais de 30 dias (find "$origem" -maxdepth 1 -type f -mtime +30).
  • Pelo conteúdo: use file --mime-type -b "$arq" (que diz image/jpeg, application/pdf…) em vez da extensão.
  • Desfazer: escreva desorganizar.sh, que lê o log e devolve cada arquivo ao lugar.
  • Automático: rode toda noite com o cron (veja Agendar Scripts).

Resumo

  • Percorra arquivos com for arq in "$pasta"/*, nunca com $(ls), e mantenha "$arq" entre aspas.
  • Um case ${nome,,} com vários padrões por linha classifica extensões em qualquer caixa.
