Bash Comandos Internos

Um comando interno (builtin) é um comando que faz parte do próprio Bash: não existe um arquivo dele em /usr/bin, e ele roda dentro do shell, sem criar processo. Alguns precisam ser internos, porque mexem no próprio shell (cd, export, source); outros são internos só por velocidade (echo, printf, test). Esta página lista os 61 do Bash 5.3, agrupados por assunto.

Como usar esta referência
  • Cada linha tem: o comando, o que faz, as opções mais usadas, um exemplo com o resultado (conferido no Bash 5.3, em português) e a aula onde ele é explicado.
  • No exemplo, → separa o comando do que ele mostra.
  • A ajuda completa de qualquer um está no próprio Bash: help nome (curta: help -d nome). Veja Obtendo Ajuda.
  • Use Ctrl+F do navegador para achar um comando.

O printf e a vírgula decimal

Com o sistema em português, o printf do Bash espera números com vírgula: printf '%.2f' 3.14159 dá bash: printf: 3.14159: número inválido (e mostra 3,00), enquanto printf '%.2f\n' 3,14159 dá 3,14. Em scripts, use LC_NUMERIC=C printf … para ter sempre o ponto.

Não são comandos internos: palavras reservadas

Estes nomes parecem comandos, mas são palavras reservadas (keywords) da gramática do Bash: só têm sentido no começo de um comando, e o Bash as reconhece antes de qualquer expansão. Por isso [[ ]] aceita && e < lá dentro, e [ não. Lista: compgen -k.

$ compgen -k | tr "\n" " "
if then else elif fi case esac for select while until do done in function time { } ! [[ ]] coproc

E (( )), que também não é comando interno: é uma construção da gramática (veja Contas).
