Bash Obtendo Ajuda

Ninguém decora todas as opções de todos os comandos. O que os veteranos sabem é onde procurar. O Bash e o sistema trazem manuais embutidos, que funcionam sem internet. Nesta aula você vai aprender qual ajuda usar para cada tipo de comando e como ler o que ela mostra.

Você vai aprender
  • A descobrir o que é um comando com type, antes de procurar a ajuda.
  • help para os comandos internos do Bash; --help, man e info para os programas.
  • A ler uma sinopse: [ ], ..., | e palavras a substituir.
  • A navegar e buscar dentro do man bash.
  • A achar um comando quando você não sabe o nome (apropos, whatis).

Primeiro: o que é esse comando?

A aula Anatomia de um Comando mostrou que um nome pode ser um comando interno do Bash ou um programa separado. Isso decide onde está a ajuda, como numa biblioteca: livros do Bash numa estante, livros dos programas em outra. O type diz em qual estante procurar.

type
Comando interno que diz o que um nome é.
cd wc ll
Os nomes que você quer investigar (quantos quiser).
$ type cd wc ll
cd é um comando interno do shell              « ajuda com help
wc é /usr/bin/wc                              « um programa: ajuda com --help e man
ll está apelidada para `ls -alF'              « um apelido: a ajuda é a do ls

type -t: uma palavra só

Com -t (type, "tipo"), a resposta é uma palavra, boa para scripts:

$ type -t cd ls wc ll if
builtin                            « comando interno
alias                              « apelido (na Ana, ls é um apelido de ls --color=auto)
file                               « arquivo: programa no disco
alias
keyword                            « palavra-chave da linguagem (if, for, while…)

type -a: todos os lugares

Um mesmo nome pode existir em vários lugares. Com -a (all, "todos"), o type lista todos, na ordem em que o Bash procura. O primeiro é o que vale:

$ type -a echo
echo é um comando interno do shell            « este é o que roda quando você digita echo
echo é /usr/bin/echo                          « existe também um programa echo…
echo é /bin/echo                              « …visto por dois caminhos (/bin aponta para /usr/bin)

Por isso man echo pode mostrar opções diferentes das do echo que você usa: o manual é do programa /usr/bin/echo, mas quem roda é o comando interno. Para o interno, a ajuda certa é help echo.

Missão: a Ana usa um comando ll. Descubra com type o que ele é de verdade. Aproveite para testar type cd, type wc e type -a echo.

help: a ajuda dos comandos internos

O help é o manual embutido no próprio Bash. Sozinho, ele lista todos os comandos internos e palavras-chave, cada um com a sua sinopse (a forma de usar):

$ help
GNU bash, versão 5.3.9(1)-release (x86_64-pc-linux-gnu)
Esses comandos shell são definidos internamente. Digite `help' para ver essa
lista. Digite `help NOME' para descobrir mais sobre a função `NOME'.
Use `info bash' para descobrir mais sobre o shell em geral.
Use `man -k' ou `info' para descobrir mais sobre comandos que não estão nesta
lista.

Um asterisco (*) próximo ao nome significa que o comando está desabilitado.

 ! PIPELINE                              history [-c] [-d posição] [n] ou his>
 espec_job [&]                           if COMANDOS; then COMANDOS; [ elif C>
 (( expressão ))                         jobs [-lnprs] [espec_job ...] ou job>
…                                        « encurtado: são mais de 70 itens em duas colunas

O > no fim de algumas linhas indica que a sinopse foi cortada para caber na coluna. Para ver um comando inteiro, peça-o pelo nome:

$ help cd
cd: cd [-L|[-P [-e]]] [-@] [dir]                       « a sinopse
    Altera o diretório de trabalho do shell.            « o que faz, em uma linha

    Altera o diretório atual para DIR, sendo o padrão de DIR o mesmo valor
    da variável HOME. Se DIR é "-", é convertido para $OLDPWD.
…                                                       « encurtado
    Opções:
      -L	força links simbólicos a serem seguidos: resolver links simbólicos
      		em DIR após processar instâncias de `..'
      -P	usa a estrutura do diretório físico sem seguir links
    		simbólicos: resolve links simbólicos em DIR antes de processar
    		instâncias de `..'
…
    Status de saída:                                    « o código de saída, explicado
    Retorna 0, se o diretório tiver sido alterado e se $PWD está definida com
    sucesso quando a opção -P for usada; do contrário, retorna não-zero.

Toda página do help tem a mesma estrutura: sinopse, resumo, descrição, Opções, às vezes Argumentos, e Status de saída. Essa última parte responde "o que o comando devolve", e quase ninguém lê.

Atalho: --help também funciona nos internos

No Bash atual, cd --help mostra o mesmo que help cd. Assim você pode usar --help em quase tudo, sem pensar se é interno ou programa.

Missão: use o help para descobrir, em uma linha, o que fazem cd e pwd (dica: -d). Depois veja só a sinopse do echo.

Como ler uma sinopse

A sinopse é a "receita" do comando escrita de forma compacta. Os mesmos símbolos aparecem no help, no man e no --help. Veja a do cd:

cd [-L|[-P [-e]]] [-@] [dir]
cd
O nome do comando: digite exatamente assim.
[-L|[-P [-e]]]
Colchetes = opcional. Dentro, | = "ou": use -L ou -P. O [-e] dentro do -P quer dizer que -e só faz sentido junto com -P.
[-@]
Outra opção opcional, independente.
[dir]
Um argumento opcional. Palavras que não são opções (dir, DIR, arquivo) são para você substituir por um valor seu.

Agora a do echo e a do type:

echo [-neE] [arg ...]
type [-afptP] nome [nome ...]
SímboloSignificaExemplo
[ ]Opcional: pode deixar de fora[dir]: cd sozinho funciona
sem colchetesObrigatórionome no type: precisa de pelo menos um
...Pode repetir[nome ...]: quantos nomes quiser
|Escolha um ou outro-L|-P
[-neE]Qualquer combinação dessas letrasecho -n, echo -ne
MAIÚSCULAS, <nome>, itálicoTroque pelo seu valor[ARQUIVO]... → frutas.txt
Não digite os colchetes

cd [dir] quer dizer cd Documentos, e não cd [Documentos]. Os símbolos da sinopse são da explicação, não do comando.

--help: a ajuda rápida dos programas

Quase todo programa aceita a opção --help, que mostra um resumo das opções direto na tela. É o jeito mais rápido de lembrar uma opção:

$ wc --help
Uso: wc [OPÇÃO]... [ARQUIVO]...
 ou: wc [OPÇÃO]... --files0-from=A
Imprime totais de novas linhas, palavras e bytes para cada FICHEIRO, e uma linha
de totais se mais de um FICHEIRO for especificado. Uma palavra é uma sequência
não-vazia de espaços não-brancos delimitada por espaços ou pelo início ou fim da entrada.

Se ARQUIVO não for especificado ou for -, lê a entrada padrão.
…                                                   « encurtado: depois vem a lista de opções

Leia a sinopse wc [OPÇÃO]... [ARQUIVO]...: opções são opcionais e podem ser várias; arquivos também. "FICHEIRO" é a palavra de Portugal para "arquivo": a tradução mistura as duas. Quando a ajuda é longa, use wc --help | less para rolar com calma (o | é explicado em Pipes).

man: o manual completo

man vem de manual. Cada programa instalado traz uma página de manual com tudo: descrição, todas as opções, exemplos, arquivos relacionados. As páginas costumam estar em inglês.

Os exemplos de man nesta seção são ilustrativos: o terminal simulado e o laboratório do guia não abrem o man, porque ele é um programa de tela cheia.

$ man wc

O man bash e como buscar nele

O manual do próprio Bash é um livro: são mais de 7 mil linhas, em inglês. Ninguém lê de ponta a ponta; você busca. O começo dele (ilustrativo):

$ man bash
BASH(1)                     General Commands Manual                    BASH(1)

NAME
       bash - GNU Bourne-Again SHell

SYNOPSIS
       bash [options] [command_string | file]

COPYRIGHT
       Bash is Copyright (C) 1989-2025 by the Free Software Foundation, Inc.
…

Digite /HISTCONTROL e Enter para pular até a variável HISTCONTROL; n vai para a próxima vez que ela aparece. Um truque: as definições ficam recuadas, então buscar com espaços no começo acha a definição em vez das menções. Digite /^ +HISTCONTROL (o ^ quer dizer "começo da linha" e +, "um ou mais espaços").

Ajuda do Bash em formato de manual, só dos internos

No Debian e no Ubuntu, man bash-builtins abre só a parte dos comandos internos do manual do Bash, bem menor que o man bash inteiro.

As seções do manual

Algumas palavras são, ao mesmo tempo, um comando e um arquivo. passwd é o comando que troca a senha e o arquivo /etc/passwd. Por isso o manual é dividido em seções numeradas:

SeçãoConteúdoExemplo
1Comandos do usuárioman 1 passwd (o comando)
5Formatos de arquivos de configuraçãoman 5 passwd (o arquivo /etc/passwd)
7Assuntos diversosman 7 bash-builtins
8Comandos do administradorman 8 useradd

info: o manual em capítulos

O projeto GNU escreve a documentação mais completa no formato info, com capítulos e links, como um livro. Para o Bash e as ferramentas GNU, às vezes o info tem exemplos que o man não tem. Exemplo ilustrativo:

$ info bash                        « o manual do Bash em capítulos
$ info coreutils 'wc invocation'   « direto no capítulo do wc

Dentro do info: Espaço rola, Tab pula para o próximo link, Enter segue o link, l volta (last), q sai. Se o info não estiver instalado, ele mostra a página do man. O mesmo conteúdo está publicado em gnu.org/software/bash/manual.

apropos e whatis: quando você não sabe o nome

E quando você nem sabe qual comando procurar? O apropos ("a propósito") procura uma palavra nas descrições de todas as páginas de manual. O whatis ("o que é") mostra a descrição de uma linha de um comando que você já conhece. Saídas ilustrativas:

$ whatis bash ls wc
bash (1)             - GNU Bourne-Again SHell
ls (1)               - list directory contents
wc (1)               - print newline, word, and byte counts for each file
$ apropos "word count"
word count: nada apropriado.       « a frase exata não aparece em nenhuma descrição
$ apropos -s 1 password            « só na seção 1, com a palavra "password"
chage (1)            - change user password expiry information
expiry (1)           - check and enforce password expiration policy
…                                  « encurtado: a lista depende do que está instalado
passwd (1)           - change user password
…

Como as descrições estão em inglês, procure em inglês: apropos copy, apropos compress, apropos user. man -k palavra é o mesmo que apropos palavra, e man -f nome, o mesmo que whatis nome.

Quando não funciona

"Nenhuma entrada de manual para cd"

Saída ilustrativa (o laboratório não roda o man):

$ man cd
Nenhuma entrada de manual para cd

O que aconteceu: cd é um comando interno do Bash. Comandos internos não têm página de manual própria: a ajuda deles está no help (e dentro do man bash).

Como confirmar: type cd responde "comando interno do shell".

Como resolver: help cd.

"nenhum tópico de ajuda corresponde" 
$ help ls
bash: help: nenhum tópico de ajuda corresponde a `ls'.  Tente `help help' ou `man -k ls' ou `info ls'.
$ echo $?
1

O que aconteceu: o caso contrário: ls é um programa, não um comando interno, e o help só conhece os internos. A própria mensagem sugere o caminho.

Como resolver: ls --help ou man ls.

O man echo mostra opções que não funcionam

O que aconteceu: o manual é do programa /usr/bin/echo, mas quando você digita echo, roda o comando interno, que é outro (veja type -a echo). Os dois são parecidos, mas não idênticos; o mesmo vale para printf, kill, test e pwd.

Como resolver: para o que você digita no Bash, confie no help echo.

"não encontrado" no type 
$ type xyz
bash: type: xyz: não encontrado
$ echo $?
1

O que aconteceu: não há comando interno, apelido, função nem programa com esse nome. Pode ser erro de digitação, ou o programa não está instalado.

Como resolver: confira a grafia; se o programa não existe, instale-o pelo gerenciador de pacotes do sistema, ou procure um parecido com apropos.

Fiquei preso dentro do man (ou de uma ajuda longa)

O que aconteceu: o leitor de tela cheia espera teclas, não comandos.

Como resolver: aperte q. Se não funcionar, Esc e depois q, ou Ctrl+C.

Resumo

  • Comece com type: ele diz se o nome é interno, programa, apelido ou palavra-chave.
  • Internos: help nome. Programas: nome --help (rápido), man nome (completo), info nome (GNU, em capítulos).
  • Sinopse: [ ] opcional, ... repete, | escolha um, palavras em maiúsculas = substitua.
  • No man: / busca, n próxima, q sai. O man bash é para buscar, não para ler inteiro.
  • apropos acha comandos pela descrição, quando você não sabe o nome.
