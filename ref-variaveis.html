Bash Variáveis Especiais

Algumas variáveis o Bash preenche sozinho (o código do último comando, os argumentos do script, a linha atual); outras ele lê para decidir como se comportar (o prompt, o tamanho do histórico, onde procurar comandos); e outras vêm do sistema (sua pasta, sua língua). Esta é a lista das que você vai encontrar, com um exemplo de cada, conferido no Bash 5.3 da máquina da Ana.

Como ler as tabelas
  • Quem define: Bash = o shell preenche (só leia); você = o Bash lê o valor que você der; sistema = vem do login/ambiente.
  • No exemplo, → separa o comando do resultado. Valores como PIDs e horários mudam a cada execução.
  • Para ver todas as variáveis do shell: declare -p; só as exportadas (o ambiente): env ou export -p. Veja Variáveis, Escopo e export.

Parâmetros especiais

Não têm nome de letra: são símbolos. Exemplos rodados com bash vscript.sh a "b c" (um script de teste) ou no terminal. Veja Argumentos e Código de Saída.

VariávelO que guardaExemplo → resultadoAula
$?Código de saída do último comando (0 = sucesso).ls nada 2>/dev/null; echo $? → 2Código de Saída
$#Quantos argumentos posicionais ("#" = "quantos").no script: echo $# → 2Argumentos
$1 … $9, ${10}Cada argumento; do 10º em diante, com chaves.echo $1 → aArgumentos
"$@"Todos os argumentos, cada um como uma palavra separada (com aspas!).printf '[%s]' "$@" → [a][b c]Argumentos
"$*"Todos os argumentos numa palavra só, unidos pelo 1º caractere do IFS.printf '[%s]' "$*" → [a b c]Argumentos
$0O nome do script (ou do shell, no terminal).no script: echo $0 → vscript.sh; no terminal → bashArgumentos
$$O PID (número do processo) do shell. Num subshell, continua o do shell principal.echo $$ → 3001Subshells
$!O PID do último comando posto em segundo plano com &.sleep 30 & echo $! → 3120Jobs
$-As opções ligadas do shell, em letras (i = interativo, m = controle de jobs, h hash, B chaves, H ! do histórico, e u x do set).no terminal → himBHs; num script → hBset e shopt
$_O último argumento do comando anterior.echo um dois; echo $_ → dois; útil: mkdir pasta && cd $_Histórico

VariávelQuem defineO que guardaExemplo → resultado
BASH_VERSIONBashA versão, em texto.echo "$BASH_VERSION" → 5.3.9(1)-release
BASH_VERSINFOBashA versão em partes (array): maior, menor, correção…echo "${BASH_VERSINFO[@]}" → 5 3 9 1 release x86_64-pc-linux-gnu; teste: (( BASH_VERSINFO[0] >= 5 ))
BASHBashO caminho do executável do Bash em uso.echo $BASH → /usr/bin/bash
BASHPIDBashO PID do processo atual (diferente de $$ dentro de um subshell).( (( BASHPID == $$ )) && echo igual || echo diferente ) → diferente
BASH_SUBSHELLBashQuantos subshells de profundidade.echo $BASH_SUBSHELL $(echo $BASH_SUBSHELL) → 0 1
SHLVLBashQuantos Bash um dentro do outro (sobe 1 a cada bash).num script rodado do terminal: echo $SHLVL → 2
LINENOBashA linha atual do script.echo "erro na linha $LINENO" → erro na linha 4
FUNCNAMEBashArray: a função atual, quem a chamou… até main.dentro de f: echo "${FUNCNAME[*]}" → f main
BASH_SOURCEBashArray: o arquivo de cada função da pilha.echo "${BASH_SOURCE[0]}" → vscript.sh; truque: [[ ${BASH_SOURCE[0]} == "$0" ]] = "fui executado, não lido com source"
BASH_LINENOBashArray: a linha de onde cada função foi chamada.dentro de f: echo "${BASH_LINENO[0]}" → 5
PIPESTATUSBashArray: o código de cada comando do último pipeline.false | true; echo "${PIPESTATUS[*]}" → 1 0
BASH_REMATCHBashArray: o que casou no último [[ =~ ]] (0 = tudo, 1… = grupos).[[ foo123 =~ ([a-z]+)([0-9]+) ]]; echo "${BASH_REMATCH[*]}" → foo123 foo 123
BASH_ARGV0BashO mesmo que $0, mas pode ser alterado. bash 5.0+echo $BASH_ARGV0 → vscript.sh
BASH_COMMANDBashO comando sendo executado agora (útil em trap … ERR).trap 'echo "falhou: $BASH_COMMAND"' ERR; ls nada 2>/dev/null → falhou: ls --color=auto nada 2> /dev/null (já com o alias expandido)
BASH_TRAPSIGBashO número do sinal que disparou o trap atual. bash 5.3+trap 'echo sinal $BASH_TRAPSIG' USR1; kill -USR1 $$ → sinal 10
BASH_ALIASESBashArray associativo com os aliases.echo "${BASH_ALIASES[ll]}" → ls -alF
PS4vocêO prefixo das linhas do set -x (padrão + ).bash -c 'PS4="+ ${LINENO}: "; set -x; echo oi' → + 1: echo oi
BASH_XTRACEFDvocêPara qual descritor vai a saída do set -x.exec 5>trace.log; BASH_XTRACEFD=5
BASH_ENVvocêArquivo lido por todo script não interativo ao iniciar.BASH_ENV=~/.bash_scripts bash script.sh

Tempo e números aleatórios

VariávelO que guardaExemplo → resultado
RANDOMUm inteiro aleatório de 0 a 32767 a cada leitura. Atribuir um valor fixa a semente (sequência repetível).echo $RANDOM $RANDOM → 11184 4096; dado: $(( RANDOM % 6 + 1 ))
SRANDOMAleatório de 32 bits (0 a 4294967295), de fonte segura; não aceita semente. bash 5.1+echo $SRANDOM → 2469350281
SECONDSSegundos desde que o shell começou (atribuir zera a contagem).SECONDS=0; sleep 2; echo $SECONDS → 2
EPOCHSECONDSSegundos desde 1/1/1970 (o "Unix time"), sem chamar o date. bash 5.0+echo $EPOCHSECONDS → 1792157154
EPOCHREALTIMEO mesmo, com microssegundos. O separador decimal segue a língua: vírgula em português. bash 5.0+echo $EPOCHREALTIME → 1792157154,055163
BASH_MONOSECONDSSegundos de um relógio que nunca volta (não muda se alguém acertar a hora). Para medir durações. bash 5.3+echo $BASH_MONOSECONDS → 3603
TIMEFORMATO formato da saída do time.TIMEFORMAT="levou %R s"; time sleep 0.1 → levou 0,102 s
TMOUTNo terminal: fecha o shell após N segundos sem digitar. No read: tempo-limite padrão.TMOUT=600 (10 minutos)
