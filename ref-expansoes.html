Bash Cola de Expansões

Antes de executar um comando, o Bash reescreve a linha: troca {a,b} por a b, ~ pela sua pasta, $x pelo valor, *.txt pelos nomes dos arquivos… Cada uma dessas trocas é uma expansão. Esta página é a cola de todas elas, na ordem em que o Bash as faz, com um exemplo e o resultado de cada forma, conferidos no Bash 5.3.

A ordem das expansões

1. chaves → 2. til → 3. parâmetros, aritmética e substituição de comando/processo (da esquerda para a direita) → 4. separação de palavras → 5. curingas → 6. remoção de aspas. A ordem explica muita coisa: {1..$n} não funciona porque as chaves vêm antes da variável. Veja A Ordem das Expansões.

Chaves · Til · Parâmetros · Operadores @ · Arrays · Aritmética · Comando · Processo · Palavras (IFS) · Curingas · extglob · Aspas

1. Chaves { }

Geram texto, sem olhar se os arquivos existem. Não aceitam variáveis dentro ({1..$n} fica literal: use seq ou for ((…))). Veja Chaves.

FormaExemploResultado
{a,b,c}echo {a,b,c}a b c
pre{x,y}posecho arq{1,2}.txtarq1.txt arq2.txt
{N..M}echo {1..5}1 2 3 4 5
{N..M..passo} com zerosecho {01..10..3}01 04 07 10
{a..e} letrasecho {a..e}a b c d e
decrescenteecho {5..1}5 4 3 2 1
combinadasecho {a,b}{1,2}a1 a2 b1 b2
sequências combinadasecho {x..z}{1..2}x1 x2 y1 y2 z1 z2

2. Til ~

Só vale no começo de uma palavra (ou depois de = e : numa atribuição) e fora de aspas. Veja Navegar.

FormaViraExemplo → resultado
~sua pasta pessoal ($HOME)echo ~ → /home/ana
~usuarioa pasta pessoal de outro usuárioecho ~ana → /home/ana
~+a pasta atual ($PWD)echo ~+ → /home/ana
~-a pasta anterior ($OLDPWD)cd /tmp; cd; echo ~- → /tmp
"~"nada: entre aspas fica literalecho "~" → ~

Nos exemplos: x=arquivo.tar.gz, v= (existe, mas vazia), u=texto, n=Bash. Veja Variáveis e Expansão de Parâmetros.

5. Substituição de comando $( )

Roda o comando e põe a saída no lugar, sem as quebras de linha do fim. Veja Substituição de Comando.

FormaExemploResultado
$(comando)echo "hoje: $(date +%Y)"hoje: 2026
`comando` (crases, forma antiga)echo "pasta: `basename $PWD`"pasta: ana
aspas dentro de $( ) são independentesecho "$(echo "aspas "dentro" funcionam")"aspas dentro funcionam
${ comando; }: sem criar subshell bash 5.3+x=5; y=${ x=7; echo $x; }; echo "$x $y"7 7 (o x mudou no shell atual)
${| comando; }: o valor é o REPLY bash 5.3+echo ${| REPLY=valor; }valor

6. Substituição de processo <( ) e >( )

Põe no lugar um nome de arquivo (/dev/fd/63) ligado à saída (ou entrada) do comando. Para comandos que exigem arquivos. Veja Substituição de Processo.

FormaExemploResultado

comparar duas saídasdiff <(echo a) <(echo b)1c1 / < a / --- / > b
>(comando)echo oi | tee >(wc -c)oi e 3

7. Separação de palavras (IFS)

O resultado de $x, $( ) e $(( )) sem aspas é cortado nos caracteres do IFS (padrão: espaço, TAB e quebra de linha). Entre aspas, não. Veja Aspas.

SituaçãoExemploResultado
sem aspas: os espaços somemvar="a b"; echo $vara b
com aspas: intactoecho "$var"a b
outro separador para um comandoIFS=: read -r u1 u2 <<< "x:y"; echo "$u1 $u2"x y
outro separador para o shelllista="1,2,3"; IFS=,; set -- $lista; echo $#; unset IFS3

8. Curingas (globbing)

Trocados pelos nomes de arquivos que casam, em ordem alfabética. Se nada casa, o padrão fica como está. Exemplos dentro de ~/Documentos (acesso.log alunos.csv notas.txt projetos relatorio.odt). Veja Curingas.

FormaCasa comExemploResultado
*qualquer sequência (até vazia), sem pegar nomes com ponto no começoecho *.txtnotas.txt
?exatamente um caractereecho ??????.csvalunos.csv
[abc] / [a-z]um caractere da lista / do intervaloecho [an]*.txtnotas.txt
[!a] ou [^a]um caractere que não está na listaecho [!a]*notas.txt projetos relatorio.odt
com chaves(as chaves vêm antes)echo *.{txt,csv}notas.txt alunos.csv
** com shopt -s globstarqualquer número de subpastasecho Documentos/**/*.htmlDocumentos/projetos/site/index.html

Opções que mudam os curingas

OpçãoEfeitoExemploResultado

Curingas estendidos (shopt -s extglob)

Ligue numa linha antes de usar: o Bash lê a linha inteira antes de executá-la, e um shopt -s extglob; echo !(*.txt) na mesma linha dá erro de sintaxe próximo ao token inesperado `('. Dentro de [[ ]] eles já funcionam sem a opção.

FormaCasa comExemploResultado

+(pad)uma ou mais repetiçõesecho +([a-z]).logacesso.log
*(pad)zero ou mais repetições[[ 007 == *(0)7 ]] && echo simsim
?(pad)zero ou uma vezecho ?(rel)atorio.odtrelatorio.odt
combinadoecho *.@(txt|csv)alunos.csv notas.txt

Exercícios

1. Só a extensão

x=foto.da.praia.jpg. Complete para mostrar só jpg:

echo "${x}"

2. Sem a extensão

Com o mesmo x, complete para mostrar foto.da.praia:

echo "${x}"

3. Por que n=5; echo {1..$n} mostra {1..5} e não 1 2 3 4 5?

4. v= (vazia). O que echo "[${v-padrão}]" "[${v:-padrão}]" mostra?

5. Os últimos 3

Complete para mostrar os 3 últimos caracteres de x (cuidado com o espaço):

echo "${x: }"
