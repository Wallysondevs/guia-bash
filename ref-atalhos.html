Bash Atalhos do Teclado

Quem edita a linha que você digita no Bash é o readline, uma biblioteca que também é usada por outros programas (o python interativo, o gdb, o psql). Por padrão ele usa atalhos no estilo do editor Emacs. Esta página reúne os atalhos que valem a pena, os do próprio terminal, o modo vi e como mudar tudo com bind e o ~/.inputrc. Para aprender com calma, veja Editar a Linha.

Como ler as teclas
  • Ctrl+A: segure Ctrl e aperte A. Nos arquivos de configuração, aparece como \C-a.
  • Alt+B: segure Alt e aperte B (\eb). Se o Alt não funcionar (macOS, alguns terminais), aperte e solte Esc e depois a tecla: o efeito é o mesmo.
  • Ctrl+X Ctrl+E: duas combinações em sequência.
  • Todos os atalhos do readline foram conferidos com bind -p no Bash 5.3 (modo emacs, o padrão).

Do terminal (não do Bash)

Estes são tratados pelo terminal (o "driver de terminal" do sistema), não pelo readline, e funcionam também dentro de outros programas. stty -a mostra a lista:

eol2 = <undef>; swtch = <undef>; start = ^Q; stop = ^S; susp = ^Z; rprnt = ^R;

Expansões do histórico com !

Não são teclas, mas cumprem o mesmo papel: reaproveitar o que você já digitou. O Bash mostra a linha expandida antes de executá-la. Veja Histórico.

FormaViraExemplo
!!O comando anterior inteirosudo !! (repete com sudo)
!$O último argumento do comando anteriormkdir novo e cd !$
!^ / !*O primeiro / todos os argumentos do anteriorls a b e rm !*
!n / !-nO comando número n / o n-ésimo para trás!42, !-2
!textoO último comando que começa com texto!git
^velho^novoO anterior, trocando velho por novocat notsa.txt e ^ts^ta
…:pSó mostra, sem executar!git:p

Por causa disso, ! dentro de aspas duplas pode dar erro no terminal (a mensagem sai em inglês mesmo):

$ echo "oi!xyz"
bash: !xyz: event not found

Use aspas simples em textos com !, ou desligue a expansão com set +H. Em scripts ela já vem desligada.

Modo vi

Se você usa o Vim, o readline pode funcionar como ele: set -o vi (volte com set -o emacs). Você começa no modo de inserção (digitando normalmente); Esc passa ao modo de comando, onde as letras são comandos.

No modo de comandoFaz
h l / w b eCaractere à esquerda/direita / próxima palavra, palavra anterior, fim da palavra
0 / $ / ^Início / fim da linha / primeiro caractere não branco
i a / I AVolta a inserir antes/depois do cursor / no início/fim da linha
x / dw / dd / DApaga caractere / palavra / linha inteira / até o fim
cw / ccTroca a palavra / a linha (apaga e entra em inserção)
u / pDesfaz / cola
k jComando anterior / próximo do histórico
/texto Enter, depois nBusca no histórico; próxima ocorrência
vAbre a linha no editor (como o Ctrl+X Ctrl+E)

No ~/.inputrc, set editing-mode vi liga o modo vi em todos os programas que usam readline, e set show-mode-in-prompt on mostra no prompt em qual modo você está.

Ver e mudar os atalhos: bind e ~/.inputrc

ComandoFaz
bind -pLista todos os atalhos (formato do inputrc)
bind -PLista as funções e as teclas de cada uma, em texto
bind -q funçãoQuais teclas chamam a função

bind -x '"\C-xd": date'Atalho que roda um comando do shell
bind -f ~/.inputrc ou Ctrl+X Ctrl+RRelê o inputrc
$ bind -q forward-search-history
forward-search-history pode ser chamado via "\C-s".
$ bind -p | grep -E 'yank-last-arg|unix-word-rubout'
"\C-w": unix-word-rubout
# vi-unix-word-rubout (not bound)
"\e.": yank-last-arg
"\e_": yank-last-arg

Para descobrir o código que uma tecla manda, aperte Ctrl+V e depois a tecla: a seta para cima aparece como ^[[A (o ^[ é o ESC, escrito \e no inputrc).

Um ~/.inputrc recomendado

# Mantém as configurações do sistema (Page Up/Down, Home/End…)
$include /etc/inputrc

# ↑ e ↓ buscam no histórico pelo que já foi digitado
"\e[A": history-search-backward
"\e[B": history-search-forward

set completion-ignore-case on      # Tab ignora maiúsculas/minúsculas
set show-all-if-ambiguous on       # um Tab só já lista as opções
set colored-stats on               # cores na lista do Tab, como no ls
set mark-symlinked-directories on  # links para pastas ganham / no Tab

Com ele, digite git e aperte ↑: só aparecem os comandos anteriores que começam com git. Conferido no Bash 5.3:

$ bind -p | grep history-search
"\e[5~": history-search-backward
"\e[A": history-search-backward
"\e[6~": history-search-forward
"\e[B": history-search-forward

O arquivo é lido quando o terminal abre; para aplicar agora, Ctrl+X Ctrl+R. Ele faz parte do projeto Seus Dotfiles.
